# Credits

The review dimensions adapt rules from the endeavour project's `CODING_STANDARDS.md`: derive-from-state over syncing effects (Declarative), the deletion test for abstractions (Composable), children over configuration props with the `showHeader`/`renderActions` violation shape (Projection first), one defining home per concept (Single source per meaning), and function declarations over arrow expressions with the handler/callback/one-liner exemptions (Declare functions and exports).
